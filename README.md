# Two Sides of Me

A personal introduction website that showcases the two sides of me: **The Builder by Day** and **The Explorer by Night**.

## About

This website was created as part of my **Training Lead application**.

The website uses a **Day and Night** theme to introduce my personality, interests, hobbies, and how I spend my time beyond study.
